Ormax

A lightweight asynchronous ORM with models, validation, relationships, query composition, nested transactions, and multiple database adapters.

Status: Beta. SQLite is covered by the bundled tests. Validate other adapters against live database servers before production deployment.

Installation

pip install ormax

# Optional backend extras
pip install "ormax[sqlite]"
pip install "ormax[postgresql]"
pip install "ormax[mysql]"
pip install "ormax[mssql]"
pip install "ormax[oracle]"

SQLite works without a third-party package through the bundled standard-library fallback. Installing aiosqlite remains supported.

Quick start

import asyncio
from ormax import CharField, Database, ForeignKeyField, Model

class Author(Model):
    name = CharField(max_length=100, index=True)

class Book(Model):
    title = CharField(max_length=200)
    author = ForeignKeyField(Author, related_name="books", null=False)

async def main():
    db = Database("sqlite:///example.db", models=[Author, Book])
    async with db:
        await db.create_tables()
        author = await Author.create(name="Ursula K. Le Guin")
        await Book.create(title="A Wizard of Earthsea", author=author)
        book = await Book.objects().select_related("author").get()
        print(book.title, book.author.name)

asyncio.run(main())

Models and fields

Defaults
Callable defaults run per instance; mutable defaults are deep-copied.
Inheritance
Abstract models contribute copied fields to concrete subclasses.
Validation
Unknown constructor fields and invalid field values raise explicit errors.
Metadata
Use class Meta or the legacy _meta dictionary.
class Timestamped(Model):
    created_at = DateTimeField(auto_now_add=True)
    metadata = JSONField(default=dict)

    class Meta:
        abstract = True

class Article(Timestamped):
    title = CharField(max_length=200, index=True)

    class Meta:
        table_name = "articles"

Public fields include text, numeric, date/time, Boolean, JSON, UUID, IP address, binary, auto-increment, and foreign-key types. Both null= and nullable= are accepted.

QuerySet API

rows = await Book.objects().filter(title__icontains="earth").all()
book = await Book.objects().get(id=1)
titles = await Book.objects().values_list("title", flat=True)
partial = await Book.objects().only("id", "title").all()
count = await Book.objects().count()
exists = await Book.objects().filter(id=1).exists()
updated = await Book.objects().filter(id=1).update(title="New")
deleted = await Book.objects().filter(id=1).delete()

Lookups: exact, iexact, contains, icontains, gt, gte, lt, lte, in, startswith, endswith, isnull, and range, including case-insensitive variants.

Relationships

book = await Book.objects().select_related("author").get(id=1)
print(book.author.name)

author = await Author.objects().prefetch_related("books").get(id=1)
books = await author.books.all()

select_related() eager-loads forward foreign keys using batched queries. prefetch_related() batches reverse relationships. It does not claim SQL JOIN semantics.

Transactions

async with db.transaction():
    author = await Author.create(name="Octavia E. Butler")
    try:
        async with db.transaction():
            await Book.create(title="Temporary", author=author)
            raise RuntimeError
    except RuntimeError:
        pass
    await Book.create(title="Kindred", author=author)

Nested contexts use savepoints. Pool-backed transactions retain one physical connection. SQLite serializes concurrent outer transactions. Active transaction contexts cannot be shared with child asyncio tasks.

Indexes

class Event(Model):
    external_id = CharField(max_length=64, index=True)

await db.create_tables()
rows = await Event.objects().using_index("idx_event_external_id").all()

create_tables() now creates declared non-unique indexes. Explicit hints are emitted for SQLite, MySQL/MariaDB/Aurora, and MSSQL. PostgreSQL does not expose native index-hint syntax through this API.

Raw SQL and safety

row = await db.fetch_one(
    "SELECT * FROM books WHERE title = ?",
    ("Kindred",),
)

Use ? placeholders and bound parameters; Ormax converts placeholders for the backend. SQL-fragment APIs such as annotate(), having(), extra(), and raw() must receive trusted SQL only.

Current limitations

  • No schema migration engine; create_tables() only creates missing structures.
  • union(), intersection(), and difference() are not implemented.
  • select_related() uses batched loading rather than joins.
  • Non-SQLite adapters require live integration testing.
  • Raw SQL-fragment APIs require trusted input.
